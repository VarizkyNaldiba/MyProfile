About Me

Hi! I'm Varizky Naldiba Rimra, born on November 10, 2003, in Padang, West Sumatra. I'm currently a student at Politeknik Negeri Malang (Polinema), pursuing my passion in technology and data science.

I'm a passionate developer and data enthusiast who loves creating innovative solutions and bringing ideas to life through code and data insights. I have a strong interest in data analysis and data science, extracting meaningful patterns from complex datasets.

Career Journey

Throughout my academic and professional journey, I've taken on diverse roles:

  • UI/UX Designer - Designed student rules and regulations system (PBL Semester 3)
  • Fullstack Developer - Developed student achievement recording system (PBL Semester 4)
  • Machine Learning Engineer - Created IoT-based seaweed pond monitoring with ML predictions (Technofair)
  • Data Analyst - Analyzed educational services accessibility (Komdigi East Java Competition)
  • Data Scientist - Developed crowd counting and temperature prediction models

Current Status

Currently, I'm actively learning and expanding my skills in:

  • Machine Learning - Learning algorithms, data preprocessing, and model building
  • Computer Vision - Image processing, object detection, and visual recognition
  • Mobile Development - Building mobile applications for Android and iOS platforms

I enjoy working with modern technologies and constantly learning new frameworks and tools to enhance my analytical and development skills. I'm always eager to take on new challenges and contribute to innovative projects.

My Philosophy

I believe that technology and data have the power to transform lives and solve real-world problems. My approach combines technical expertise with creative thinking, allowing me to build solutions that are not only functional but also user-friendly and innovative.

Whether it's analyzing complex datasets, building full-stack applications, or designing intuitive user interfaces, I bring dedication and enthusiasm to every project. I'm committed to continuous learning and staying updated with the latest technologies in the ever-evolving tech landscape.
